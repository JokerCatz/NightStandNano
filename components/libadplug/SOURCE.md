# libadplug (AdPlug 2.4 + libbinio 1.5, DOS AdLib / OPL music)

- AdPlug 2.4: <https://github.com/adplug/adplug/releases/download/adplug-2.4/adplug-2.4.tar.bz2>, sha256 `de18463bf7c0cb639a3228ad47e69eb7f78a5a197802d325f3a5ed7e1c56d57f`.
- libbinio 1.5: <https://github.com/adplug/libbinio/releases/download/libbinio-1.5/libbinio-1.5.tar.bz2>, sha256 `398b2468e7838d2274d1f62dbc112e7e043433812f7ae63ef29f5cb31dc6defd`.
- Downloaded 2026-11-18 into `.local/downloads/adplug-2.4/` and `.../libbinio-1.5/` (outside git, extracted as data, nothing built or run from there; the hashes equal the copies under `rgxx/ref`).
- Licence: LGPL-2.1-or-later (`docs/licenses/adplug-LGPL-2.1.txt`, `docs/licenses/libbinio-LGPL-2.1.txt`). Every compiled file's header was checked: the AdPlug players, `fmopl.c` ("a fork of the MAME one, relicensed under the LGPL", Tatsuyuki Satoh; AdPlug's README explains the emulator licence history), `unlzh.c` (public-domain ar002), `unlzss`/`unlzw`/`sixdepack` (LGPL).
- **Left out:** `jbm.cpp` (header says "Released under the terms of the GNU General Public License"), `adl.cpp` (Westwood ADL: carries a GPL-2+ block from ScummVM beside an LGPL block; the project rule is no GPL), `depack.c` (aPlib, "All Rights Reserved", no licence; A2M / A2T versions 9-11 are refused), `database.cpp` (and the iostream it drags in), `adplug.cpp` / `players.cpp` (std::list player table with static initialisers: replaced by `players_table.cpp`), the other emulators (`nukedopl`, `woodyopl`, `adlibemu`, `kemuopl`, `emuopl`, `temuopl`, `wemuopl`, `nemuopl`, `surroundopl`: only `fmopl.c` is used), `realopl`, `diskopl`, `analopl`, the AdPlug database file.
- Ours: `adplug_c.h/.cpp` (C API, two-chip OPL2 emulator class over fmopl, memory file provider, silent length scan, voice view, mute, PSRAM scope for C++ `new`), `players_table.cpp/.h` (the table of `adplug.cpp` minus ADL and JBM), `database.h` (stub with the file key `got.cpp` needs), `binio/binio.h` (binio.h.in configured: string yes, iostream no, ISO stdlib, math, int, double).
- Patches (`patches/0001-adplug-trim-and-hardening.patch`, `0002-binio-h-configured.patch`): no file-system provider; no database in `player.cpp` / `imf.cpp`; A2M v9-11 refused; the hardening found by fuzzing the real files under ASan/UBSan (`test_opl`): cmf instrument index, hybrid order list and note, msc block bounds, coktel command bounds, herad decompressor bounds and instrument indexes, unlzh unaligned load (RISC-V faults). Marked `libadplug patch 0001` in the sources.
- Build flags: `-Os` (`fmopl.c` -O2), `-fno-exceptions -fno-rtti -std=gnu++11 -fwrapv`, `-Dstricmp=strcasecmp`, `-msmall-data-limit=0` so `linker.lf` puts the zero-initialised statics (fmopl 33 KB, unlzh 46 KB) in PSRAM.
- Excluded from the library by extension (the players are compiled): `.mid`, `.raw`, `.m` (too generic for a music folder; `.mid` is the project decision "no MIDI files" of 2026-11-10), `.vgm` / `.vgz` / `.s3m` (other backends).
